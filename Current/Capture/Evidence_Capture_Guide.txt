EVIDENCE CAPTURE GUIDE
The attached JSON forms are empty data-entry aids, not achieved results. Populate copies using existing permissible records. Do not replace a missing record with a newly written assertion.

1. Choose the form matching the claim. Identify source and scope before calculating a result. Keep the original confidential record locally; share only the permitted anonymous extract and source hash/locator.
2. Keep all units and denominators explicit. Zero is a real observation, not a substitute for a missing value. Leave unobserved fields null. A hash identifies bytes; it does not verify their truth.
3. For account effort, record task count and baseline versus assisted time, then deduct review and exception effort. Confirm whether review is already inside assisted time before calculating. Convert minutes to person-days using the recorded working-day length. Do not add the included monthly assurance example a second time.
4. For automation coverage, divide automated eligible activities by all eligible activities for the same period and definition. Do not substitute model accuracy, conformance or rule coverage. Resolve overlap between deterministic and AI components first.
5. For NFT effort, compare equal task scopes and include review and exceptions. Percentage reduction = (baseline effort minus comparable automated effort) / baseline effort times 100, only when baseline is positive and scope comparable.
6. For cache results, pair baseline and retest under equivalent workload, duration and environment; state any difference. Retain failed runs. No percentage can be calculated without comparable numerical values.
7. For acceptance, link requirements to adequately sampled runs, defects, retests and existing role-only approval records. A failed alert demonstrates detection, not closure. A release count does not establish post-release quality.
8. For shared regression, link each team's contribution to actual pipeline execution, then show one failure, ownership decision, correction and passing rerun. Match setup timing scope before making a saving claim.
9. For adapted models, retain model artifact and serving provenance, valid independent holdout and matched base/adapted evaluation. Training code alone is not a completed training run. The currently audited dataset overlap must be resolved before claiming independent uplift.
10. Run confidentiality checks on text, metadata and images. These forms never request feedback or email material. Structured outcome, issue and approval-workflow records can be used within permission boundaries.

When records are supplied, recalculate the claims, update the papers and request another independent criterion-by-criterion review. Filling a form does not guarantee a score.
